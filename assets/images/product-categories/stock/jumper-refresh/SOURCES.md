# Jumper harness image sources

All photographs in this folder are free-to-use Pexels photographs. The numeric filename is the Pexels photo ID; its source page is `https://www.pexels.com/photo/<id>/`.

The set was selected around jumper-wire routing, board interfaces, connector conversion, electrical test, electronics assembly and controlled service work. Images are used as visual context for the adjacent technical copy and do not assert that the pictured component is a Super Smile product.
