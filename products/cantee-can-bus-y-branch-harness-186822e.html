APPLICATIONS连接的应用

Application directions应用方向

These are connection directions for project discussion. Suitability depends on interfaces, circuits, installation conditions and project validation; configuration can be adapted to the equipment.以下为可讨论的连接方向。实际适用性取决于接口、电路、安装环境和项目验证，可按设备需求调整。

Vehicle control-module leads车辆控制模块引线

Separate interface cavities, power circuits and signal circuits at controller leads. Set branch dimensions from the module and mounting-point positions. Define the CAN physical layer, target bit rate and network topology.控制模块尾线需要清楚区分接口腔位、电源和信号回路；分支尺寸应对应模块与固定点的位置。选配时，明确CAN物理层、目标速率与网络拓扑。

Module wiring within enclosures机箱内部的模块配线

Coordinate board positions, module removal and wire bends within the enclosure. Preserve insulation clearance and support behind each termination. Confirm impedance target, twist pitch and conductors from the selected cable documents.机箱内部配线需要协调板卡位置、模块拆装和导线转弯空间；端接后的绝缘与支撑不能被外壳挤压。选配时，阻抗目标、绞距与导体规格按选定电缆文件确认。

Instrument inputs and measurement leads仪器输入与测量引线

Start measurement leads from signal type, input conditions and grounding. Select pairs and shields for the actual measurement range and noise target. Specify trunk length, branch lengths and termination-resistor locations separately.测量引线以信号类型、输入条件和接地方式为起点，线对与屏蔽选择需要对应实际量程和噪声目标。选配时，分别注明主干、支路长度和终端电阻位置。

Control-signal pairs and node connections控制信号线对与节点连接

Define trunks, nodes and termination positions in control-network branches. Match pair construction and breakout length to the physical layer in use. Review shielding, grounding and environment for the complete equipment network.控制网络支路需要定义主干、节点与终端位置，线对结构和展开长度应对应所用物理层。选配时，屏蔽、接地和环境要求按完整设备网络审核。

Internal machine connections and service设备机内连接与维护

Keep internal connections clear of working zones and moving parts. Allow appropriate cable length between supports, interfaces and service paths. Define the CAN physical layer, target bit rate and network topology.设备机内连接要避开加工区与运动部件，并在固定点、接口和检修路径之间保留合理线缆余量。选配时，明确CAN物理层、目标速率与网络拓扑。

Vehicle service connections车辆检修转接位置

Provide access for mating and service tools. Record end-face views and cable retention after service; appearance alone does not establish interchangeability. Confirm impedance target, twist pitch and conductors from the selected cable documents.可拆卸尾线应保留插拔与工具空间，并记录端视图和维修后的固定方式，避免只凭外观确定替换关系。选配时，阻抗目标、绞距与导体规格按选定电缆文件确认。

PRODUCT QUESTIONS产品问答

Product & customization questions产品与定制常见问题

Can the common 120-ohm target be treated as a measured value?常见120欧目标可直接当作实测值吗？

A common 120-ohm target is not an example's measured value. Define the CAN physical layer, target bit rate and network topology.120欧常见目标不能直接填成示例实测值。明确CAN物理层、目标速率与网络拓扑。

Does every CAN cable include termination resistors?CAN电缆都自带终端电阻吗？

Termination belongs to network design and is not built into every cable. Confirm impedance target, twist pitch and conductors from the selected cable documents.终端电阻属于网络设计不是所有线缆自带。阻抗目标、绞距与导体规格按选定电缆文件确认。

Can bit rate and distance be defined independently of topology?速率和距离可以脱离拓扑确定吗？

Validate rate/distance with the complete topology. Specify trunk length, branch lengths and termination-resistor locations separately.速率与距离需结合完整拓扑验证。分别注明主干、支路长度和终端电阻位置。
